## Digital Dice Roller Guide

This application simulates rolling
a standard six-sided dice.

### Features

- Random dice results
- Interactive roll button
- Result display
- Roll history (if supported)

### How to Use

1. Open the application.
2. Click the Roll Dice button.
3. View the generated result.

### Development Notes

Use random number generation
to produce valid dice values
between 1 and 6.
## Manual Testing Checklist

- [ ] Roll the dice and verify results are between 1 and 6.
- [ ] Check that the roll counter updates.
- [ ] Reset the roll history and review the result.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
